# Application icon provenance

The calendar mark in `daybook-source.svg` is authored vector geometry for DeadlineOS. `icon-source.svg` contains the same source. The 192/512px application icons, maskable icon, 180px Apple icon, 96px badge and 48px favicon were rendered from that SVG using Sharp. No external artwork or generated bitmap illustration is used.

The dark Campus Quest version uses a charcoal background, amber calendar strokes and a blue completion check. Both source files carry the same geometry and colours.
