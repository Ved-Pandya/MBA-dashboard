# Dashboard redesign

Mode: Operate. Scope: login, application shell, student day, management publishing, and shared component system.

## Direction contract

THESIS: A campus daybook that puts the next obligation on a readable line, with management operating in the same vocabulary. Remove the oversized metric-card scaffold and marketing copy from working screens.

OWN-WORLD: Warm academic register. Deep vermilion navigation, cream pages, dark brown ink, expressive self-hosted Fraunces headings, IBM Plex Sans for actions and data, fine warm rules and clear outline SVG icons. A live India-date stamp gives the day view a recognisable calendar detail. No decorative textures, gradients or floating statistics.

STORY: A student sees what is due first, acts on it, then checks notices. A POC/CR sees the relevant workspace immediately, reviews current work and opens the editor deliberately.

FIRST VIEWPORT: A vermilion identity rail and cream utility header; a large Fraunces Today heading and live calendar date stamp; deadlines at the top of the main column; response requests and academic dates in a narrower adjacent column. Management keeps the existing records-first layout, with larger editorial headings and flat lists. Sign-in uses a full vermilion cover beside the cream credential form.

FORM: Academic register, after the user rejected the preceding blue sans-serif dashboard as generic and clarified that the visual style was the main concern. The existing usable layout is retained. Considered references: registrar ledger (clear records), academic journal (editorial type), campus bulletin (urgent notices), course reader (long-form readability), seminar programme (strong dates), library catalogue (precise metadata), and timetable (scanable groups). The concept-seed launcher was invoked but its engine remains unavailable; no seed assignment or approved comp is claimed. Manual code-led execution retains the previous fallback.

SIGNATURE INTERACTION: Completing a task changes its outlined circular control into a filled square with a check, alongside the explicit pressed state and completed list. The short transition honours reduced motion. No entrance animations delay working content.

QUALITY BAR: The visible change must be obvious in the first viewport, beyond a new hue. Serif/sans contrast, the vermilion rail, cream field, live date stamp and flat manager records must hold together at desktop and mobile widths. Controls and body data remain easy to read; the expressive type is reserved for headings, never dense table values. This is a written code-led bar, not a claimed external reference or approved image.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
