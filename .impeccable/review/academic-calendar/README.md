# Academics calendar extension

The request adds a calendar to the existing Academics page. This is an extension of the dark Campus Quest system, with no new visual world or system token changes. `PRODUCT.md`, `DESIGN.md`, `.impeccable/design.json` and the existing dashboard surface contract remain authoritative and unchanged.

The default Calendar view preserves the existing List option. Its Monday-first month grid provides previous/next month, Today, event-type filtering and a selected-day agenda. Published events, including past dates, reuse the existing Academics subscription, section query, event rows and subject edit permissions; the calendar adds no Firebase fetch. Grouping and displayed times use IST. Arrow keys, Home/End and Page Up/Down move the selected date with keyboard focus; selected state, today's date, event counts and loading feedback have accessible text/state.

The extension reuses charcoal/graphite surfaces, off-white ink, amber selection/actions, shared status colors, IBM Plex Sans, bordered controls and authored outline icons. Desktop places a 290px agenda beside the month; below 1280px it stacks. At 640px and below, day cells use compact counts instead of title previews, the filter expands, and the agenda retains full details. These are local calendar adaptations, not new system-wide rules.
